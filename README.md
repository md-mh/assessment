# iBOS Online Assessment Platform

Initial scaffold for the interview task using:

- Next.js App Router
- Redux Toolkit
- TanStack Query
- React Hook Form
- Yup
- Tailwind CSS

Current progress:

- Base project structure
- Shared providers and store setup
- Mock auth slice
- Login page UI based on the provided design

## Run locally

1. Install dependencies:

```bash
npm install
```

2. Start the app:

```bash
npm run dev
```
